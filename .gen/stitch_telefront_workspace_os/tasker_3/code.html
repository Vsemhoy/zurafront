# Контекст Текущая система авторизации использует устаревший подход с сессионными cookie, что затрудняет масштабирование и интеграцию с мобильными клиентами. Необходимо перевести ядро авторизации на stateless архитектуру с использованием JWT. ## Задачи - [x] Анализ текущих зависимостей от сессий в монолите - [ ] Разработка сервиса генерации токенов (Access/Refresh) - [ ] Обновление миддлвари для валидации JWT - [ ] Механизм инвалидации (Redis blacklist для refresh токенов) - [ ] Адаптация фронтенда под отправку заголовка `Authorization: Bearer` ### Критерии приемки 1. Успешный логин возвращает пару токенов (access 15m, refresh 7d) 2. Все защищенные эндпоинты корректно валидируют токен 3. Сохранена обратная совместимость для эндпоинтов `/api/v1/legacy/*` на период миграции.
